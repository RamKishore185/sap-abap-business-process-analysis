# GitHub Upload Guide

1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload the contents of this folder (not the ZIP file itself, if you want the folders to appear normally).
4. Commit the files to the `main` branch.
5. Open the repository homepage and copy its actual URL for your internship submission.

Before publishing, replace `[Your Full Name]` in `README.md` and the Word document. Check that public visibility is permitted by your internship provider. This is a design-stage project; only add implementation code after you have actually developed and tested it.
